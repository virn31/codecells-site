Aviso de Privacidad

Este aviso describe cómo CODE CELLS® (en adelante, "la Red") recopila, usa y protege la información de pacientes, médicos afiliados y visitantes de codecells.mx, incluyendo el uso de integraciones con servicios de terceros como Google Calendar.

1. Responsable del tratamiento

CODE CELLS® es una red de medicina regenerativa con sede en Culiacán, Sinaloa, México. Para cualquier duda sobre este aviso o sobre tus datos, puedes escribir a través de los canales de contacto listados al final de esta página.

2. Datos que recopilamos

Dependiendo de tu rol dentro de la plataforma, podemos recopilar:

  • Pacientes: nombre, edad, sexo, datos de contacto, historia clínica, resultados de laboratorio/estudios de imagen, y notas de consulta capturadas por su médico tratante.
  • Médicos afiliados: nombre, cédula profesional, especialidad, datos de contacto, y — de forma opcional — la conexión a su cuenta de Google Calendar.

3. Integración con Google Calendar

¿Qué acceso solicitamos? Si un médico elige conectar su Google Calendar desde el Portal Médico, solicitamos permiso para crear eventos en su calendario (alcance calendar de Google) y para identificar la cuenta conectada (su correo).

¿Para qué lo usamos? Únicamente para agregar automáticamente las citas de consulta que el médico confirma dentro del Portal Médico a su propio calendario de Google — como una comodidad para no tener que capturarlas manualmente dos veces.

¿Con quién se comparte? Con nadie. Los datos de tu calendario no se comparten con otros médicos, pacientes, ni terceros, y no se usan para publicidad ni se venden bajo ninguna circunstancia.

¿Cómo puedo revocar el acceso? En cualquier momento desde myaccount.google.com/permissions, buscando "CODE CELLS®" y eliminando el acceso. Esto no afecta el resto de tu cuenta de médico en el Portal, solo detiene la sincronización de citas.

El uso que CODE CELLS® hace de la información recibida de las APIs de Google se apega a la Google API Services User Data Policy, incluyendo los requisitos de Uso Limitado (Limited Use).

4. Cómo usamos la información clínica

La información capturada en el expediente clínico (historia, consultas, laboratorios, protocolos) se usa exclusivamente para fines de atención médica dentro de la Red CODE CELLS® — por el médico tratante, y por especialistas de la red en casos de interconsulta explícitamente solicitada. NOVA, nuestro asistente de inteligencia artificial, procesa esta información únicamente para asistir al médico o al paciente dentro de la plataforma; no se utiliza para entrenar modelos de terceros ni se comparte fuera de la Red.

5. Seguridad

Los datos se almacenan en infraestructura con controles de acceso restringidos, y las credenciales de acceso a servicios externos (como los tokens de Google) nunca se exponen del lado del navegador — se manejan exclusivamente en nuestros servidores.

6. Tus derechos

Como paciente o médico, puedes solicitar acceso, corrección o eliminación de tu información en cualquier momento contactando directamente a tu médico tratante o al equipo de CODE CELLS®.

7. Cambios a este aviso

Este aviso puede actualizarse periódicamente. La fecha de última actualización se indica al inicio de esta página.
