Aviso de Privacidad

Este aviso describe cómo CODE CELLS™ (en adelante, "la Red") recopila, usa y protege la información de pacientes, médicos afiliados y visitantes de codecells.mx, incluyendo el uso de integraciones con servicios de terceros como Google Calendar.

1. Responsable del tratamiento

CODE CELLS™ es una red de medicina regenerativa con sede en Culiacán, Sinaloa, México. Para cualquier duda sobre este aviso o sobre tus datos, escríbenos a privacidad@codecells.mx.

2. Datos que recopilamos

Dependiendo de tu rol dentro de la plataforma, podemos recopilar:

  • Pacientes: nombre, edad, sexo, datos de contacto, historia clínica, resultados de laboratorio/estudios de imagen, y notas de consulta capturadas por su médico tratante.
  • Médicos afiliados: nombre, cédula profesional, especialidad, datos de contacto, y — de forma opcional — la conexión a su cuenta de Google Calendar.

3. Integración con Google Calendar

¿Quién la usa? Solo los médicos afiliados que deciden conectar su Google Calendar, desde el Portal Médico o desde el asistente de CODE CELLS™ en Telegram. Es opcional: sin conectarla, la agenda de CODE CELLS™ funciona igual con el horario que el médico configura.

¿Qué acceso solicitamos? Tres permisos, y nada más:

  • Correo de la cuenta (userinfo.email): para mostrarle al médico qué cuenta quedó conectada.
  • Disponibilidad (calendar.freebusy): saber a qué horas el médico está ocupado. Solo recibimos los bloques de tiempo ocupados; no vemos títulos, descripciones, participantes ni ningún otro detalle de sus eventos.
  • Eventos (calendar.events): crear en su calendario el evento de cada cita que se agenda con él en CODE CELLS™, y borrarlo si la cita se cancela. No modificamos ni borramos ningún evento que no hayamos creado.

¿Para qué lo usamos? Únicamente para que el directorio de CODE CELLS™ ofrezca a los pacientes solo los horarios en que el médico está libre, y para que las citas agendadas aparezcan en su propio calendario. El evento de la cita lleva el nombre y teléfono del paciente que la agendó (nunca el motivo de consulta), para que el médico sepa a quién recibe.

¿Qué guardamos? El permiso de acceso que entrega Google (token), el correo de la cuenta conectada y el identificador de cada evento que creamos (para poder borrarlo si la cita se cancela). No guardamos ni copiamos el contenido del calendario del médico.

¿Con quién se comparte? Con nadie. La información recibida de Google no se comparte con otros médicos, pacientes ni terceros, no se usa para publicidad, no se vende y no se usa para entrenar modelos de inteligencia artificial.

¿Cómo puedo revocar el acceso? En cualquier momento desde myaccount.google.com/permissions, buscando "CODE CELLS" y quitando el acceso. Al detectarlo, borramos el permiso guardado y la agenda automática pasa a modo de solicitudes. También puedes pedir que borremos todos los datos de la conexión escribiendo a privacidad@codecells.mx.

El uso que CODE CELLS™ hace de la información recibida de las APIs de Google, y su transferencia a cualquier otra aplicación, se apega a la Google API Services User Data Policy, incluidos los requisitos de Uso Limitado (Limited Use).

Google Calendar integration (English summary)

Only affiliated physicians who choose to connect their Google Calendar use this integration. CODE CELLS™ requests three scopes: userinfo.email (to show which account is connected), calendar.freebusy (to know when the physician is busy — we receive busy time blocks only, never event titles, descriptions or attendees) and calendar.events (to create an event for each appointment booked with the physician through CODE CELLS™, and to delete it if the appointment is cancelled; we never modify or delete events we did not create).

We store only the OAuth token, the connected account's email and the IDs of the events we create. Google user data is not shared with other physicians, patients or third parties, is not used for advertising, is not sold, and is not used to train AI models. Access can be revoked at any time at myaccount.google.com/permissions; data deletion requests: privacidad@codecells.mx.

CODE CELLS™'s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Cómo usamos la información clínica

La información capturada en el expediente clínico (historia, consultas, laboratorios, protocolos) se usa exclusivamente para fines de atención médica dentro de la Red CODE CELLS™ — por el médico tratante, y por especialistas de la red en casos de interconsulta explícitamente solicitada. NOVA, nuestro asistente de inteligencia artificial, procesa esta información únicamente para asistir al médico o al paciente dentro de la plataforma; no se utiliza para entrenar modelos de terceros ni se comparte fuera de la Red.

5. Seguridad

Los datos se almacenan en infraestructura con controles de acceso restringidos, y las credenciales de acceso a servicios externos (como los tokens de Google) nunca se exponen del lado del navegador — se manejan exclusivamente en nuestros servidores.

6. Tus derechos

Como paciente o médico, puedes solicitar acceso, corrección o eliminación de tu información en cualquier momento contactando directamente a tu médico tratante o al equipo de CODE CELLS™.

7. Cambios a este aviso

Este aviso puede actualizarse periódicamente. La fecha de última actualización se indica al inicio de esta página.
